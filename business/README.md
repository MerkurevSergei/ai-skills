# Бизнес-скиллы

Мини-скиллы Claude про продажи и маркетинг: креативы, заголовки, лендинги, офферы. Каждый скилл лежит в своей папке с файлом `SKILL.md`.

| Скилл | О чём |
|---|---|
| [selling-creative](selling-creative/SKILL.md) | Продающий креатив: узнал себя → понял выгоду → получил предложение |
| [landing-first-screen](landing-first-screen/SKILL.md) | Первый экран за 8 секунд: что получу, как работает, чем докажете, одна кнопка |
| [landing-page](landing-page/SKILL.md) | Весь лендинг: заголовок → боли → как работает → одно действие |

Связка: креатив обещает → первый экран подтверждает теми же словами → страница доводит до действия.
